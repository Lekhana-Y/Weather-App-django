# Django Weather App 🌦️

A modern weather dashboard built with Django that allows users to search cities and view real-time weather data with a clean UI.

## Features

- Search any city
- Real-time weather data using OpenWeather API
- City images
- Temperature display
- Weather description
- Weather icons
- Delete city option
- Duplicate city prevention
- Error handling for invalid cities
- Responsive Bootstrap UI

## Tech Stack

Backend:
- Django
- Python
- SQLite

Frontend:
- HTML
- CSS
- Bootstrap

APIs:
- OpenWeather API
- Picsum Photos (city images)
